One funny line, at most 200 characters, roasting my own AI agent.

> I asked my agent to roast itself. It spawned twelve subagents, wrote a 25-megabyte apology, and billed the transcript as the joke.

`main.py` writes `entry.txt` to `/output/entry.txt` (UTF-8, 1–200 chars, one line, mode 0644).
